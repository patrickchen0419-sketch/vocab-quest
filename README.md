# 單字闖關 🎯

依「大學入學考試中心《高中英文參考詞彙表》（111 學年度起適用）」出題的單字闖關遊戲。
本機純靜態網站，**雙擊 `index.html` 就能玩，不需要網路、不需要伺服器**。

> **畫面看起來沒更新？** 那是瀏覽器快取。按 **Ctrl + Shift + R** 強制重新整理（`index.html` 已經加了
> no-cache 標頭與 `?v=25` 版號，但舊分頁還是可能抓到舊檔）。改過 `src/` 之後把 `index.html` 裡的 `?v=` 數字 +1 最保險。

## 關卡結構

```
首頁（就是闖關地圖，列出 6 個大關）
  └── 大關（級別 1～6，1 最簡單、6 最難）
        └── 字母關（A～Z，詞彙表沒有 X 開頭的字）
              └── 選這次要練幾個字 → 開始
```

點級別 → 選字母 → **選這一次要練幾個字**（5／10／15／20／30／全部）→ 開始。

**取字順序（只在這一關的字裡挑，絕不外借別的字母）：**

1. **還沒學過的字優先** —— 這才是真正的進度
2. 但保留**最多 ¼** 的名額給「今天到期或曾經答錯」的本關字，
   否則只要這個字母還有新字，錯過的字就永遠排不到（錯題加權會失效）
3. 剩下的名額才輪到其他學過的字，練熟的（box 3 以上）排最後

**這一輪通過：正確率 90%。** 沒有 90% 就是沒通過，要重來 —— 那一關的 XP 與金幣都不算。
星數：全對 ★★★、95% 以上 ★★、90～95% ★。

**真正「打完」一關要 100% 完成度** —— 這個字母的字全部學會（每個字至少進到 box 1）。

| 狀態 | 結算畫面給的按鈕 |
|---|---|
| 這一輪通過，但完成度 < 100% | **「繼續練習（新單字 N 個）」** —— 同一個字母再開一關，出還沒學過的字 |
| 這一輪通過，完成度 = 100% | **「下一關 →」** ＋ 字母磚顯示 ★★★ |
| 沒過（< 90%） | 「再挑戰一次」 |

字母磚上的數字就是完成度；只有 100% 才會變成星星。

## 每一關怎麼跑

1. 這一關裡有沒學過的字 → 先一張張出**學習卡**（釋義、音標、詞形變化、例句）。
   學習卡右上角有 **⚙ 暫停**：這階段還沒開始計時，可以休息，也可以先離開（不算失敗，下次重看）。
2. 開始作答。**每一題都有時間限制**，但額度按題型給：

   | 題型 | 秒數 | | 題型 | 秒數 |
   |---|---|---|---|---|
   | 英→中 / 中→英 | 15 | | 例句克漏字 | 30 |
   | 聽發音 / 易混淆字 | 18 | | 中譯英填空 | 45 |
   | 詞形變化 | 20 | | 句子重組 | 75 |
   | 拼字 | 35 | | 找錯改錯 | 90 |

   逾時若已經打了字，仍會照你打的內容判分，不會白扣。難度會等比縮放這張表。
   **越快答對，分數越高**：每題分數 = 底分 10 ＋ 速度分（最多 +10，用完時間就沒有）＋ 連擊分 ＋ 里程碑獎勵，再乘難度倍率。
   拼字題**只給字數提示**（`_______`），連首字母都不給。
3. **每一關的題型組成**（總題數不變，名額固定保留）：

   | 一關 12 題 | 內容 |
   |---|---|
   | 2 題 | **句子運用**：例句克漏字／中譯英填空／句子重組，其中一半機率有一題**自由造句**（給我批改的材料）。<br>取字範圍**只有兩層**：這一關抽到的字 → **同一級、同一個字首**的其他字。<br>**湊不到就直接不出那一題**，名額改考本關的單字 —— 關卡裡永遠不會出現別級或別字母的字 |
   | 1 題 | **文法**：優先考**這一關的字連到的文法點**（例句在 `sentences.js` 有 `gp` 連結，題面會標「來自這一關的 issue」）；<br>沒有連結時按級別對應文法藍圖的階段（1–2 級 → 第一階、3–4 → 第二階、5 → 第三階、6 → 第四階） |
   | 9 題 | 單字題 —— 但**只要那個字有例句，就有約 50% 機率直接考句子**而不是四選一 |

   插入的句子／文法題會平均散在考卷中間，不會全擠在最後。
   複習關中間也會插一題文法。三個名額都可以在設定頁調（0 = 關掉）。

4. **重新挑戰會換題目**：不是同一份考卷再來一次 ——
   剛剛**答錯的字一定再考，但換一種題型**；剛剛**答對的字換成別的字**。
   闖關、複習、訂正、錯題關、難字關、加碼題、自訂練習全都適用（字不夠時才會重複）。
5. **答完當下不對答案**，直接進下一題。要到**整關結束才一次結算**，附逐題檢討（答錯的排前面，給正確答案與說明）。
   想改成每題立刻對答案，設定裡可以開。
6. 血量歸零 → GAME OVER，該關 XP 全部作廢、連勝歸零，可以重來、用**復活石**續命，或先訂正錯的字。
7. 通關 → **開寶箱**（表現越好箱子越好）。開箱前還可以挑戰一題**加碼題**：答對寶箱升一級，答錯不倒扣。

每一關都會記下**開始時間、結束時間、實際用時**；結算畫面顯示「本關用時／平均每題」，紀錄頁看得到全部歷史。

**關卡進行中沒有任何返回按鈕。** 右上角只有 **⚙ 齒輪**：按下去就是暫停，選單裡才有「離開（放棄這一關）」。
放棄＝不算通過、連勝歸零、XP 不入帳 —— 但**作答紀錄一定保留**，答錯的字照樣進複習與家長回報。

## 難度

| | ♥ | 時間 | 題型偏向 | XP |
|---|---|---|---|---|
| 輕鬆 | 8 | ×1.6 | 多考「認得出來」 | ×0.8 |
| 標準 | 5 | ×1.0 | — | ×1.0 |
| 挑戰 | 3 | ×0.75 | 多考「拼得出來」 | ×1.3 |
| 地獄 | 1 | ×0.55 | 多考「拼得出來」 | ×1.6 |

系統會依你最近三天的正確率推薦難度（標 ⭐）。**選建議難度或更難，過關 XP 有 ×1.2 適配加成** —— 一直待在輕鬆模式拿不到。

難度和題數是**兩個獨立的設定**：難度管血量／時間／題型難易，題數在開關卡前自己選。

## 連擊與連勝

**連擊＝關卡連擊**：同一關裡連續答對才累加，答錯或換到下一關就從 0 開始。
每 5 連擊多 2 分，並在 5／10／15／20／30／40／50 連擊時給里程碑獎勵。

## 連勝（跨關）

連續通關會累積 ⚡ 連勝，**每連勝一關 XP +8%，最多 +80%**。失敗、血空或放棄都會歸零。
商店的「連勝護盾」可以在失敗時自動擋一次。

## 快速篩選：本來就會的字不用當新字學（⚡）

詞彙表 6012 字裡有一大堆小學就會的字（第 1–2 級尤其多），全部當「新字」走學習卡是浪費時間。
首頁 →「⚡ 快速篩選」：

1. 一次看 **12 個字**（英文＋詞性＋級別），**只點掉不會的**（不確定意思的也算不會）。
2. 沒點的字＝你說會 → 系統從裡面**隨機抽 2 個真的考**（英→中 四選一，10 秒）。
3. 抽考過 → 整批算已會，放進 **box 2**（**3 天後照樣會出現在複習裡**，忘了就會被抓出來）。
   抽考沒過 → 整批只放到 box 1，**明天重考**；答錯的那個直接排進學習隊列。
4. 點掉的字 → 進學習隊列，之後照樣出學習卡與完整題型。

一批約 20–40 秒，第 1＋2 級共 2004 字大約 1.5–2 小時篩完，之後就再也不會被當新字考。

- 這些字**不算「今天學的新單字」**（那不是今天學的），家長回報會另外列一行：
  `■ 快速篩選：確認「本來就會」N 字（不列入新學）、挑出 N 字要學；抽考 N 題對 N 題`
- 抽考題也**不混進「今天複習的單字」**統計，分開記。
- 學習卡上也有 **「這個我早就會了 ⏭」**：同樣是 box 2，不算今天的新字。

## 衝刺目標（🎯 每天要學幾個字讓網站自己算）

在首頁按預設鈕或到設定頁，訂一個「**哪天之前**學會**幾個字**（哪個級別）」，之後首頁會顯示：

- **今天還要學幾個字** ＝（目標 − 已學會）÷ 剩下天數 —— 落後了數字自己變大，不用手動改計畫
- 倒數天數、範圍總進度、今天配額的進度條
- 這個配額同時變成一個**每日任務**（獎勵 100 XP / 40 🪙），完成當天的量就自動入帳
- 如果算出來每天超過 120 字，會直接標紅警告「這個量學不進去」，建議延期限或縮範圍

參考數字（含間隔複習的實際負擔）：

| 每天新字 | 含複習的每天題數 | 每天時間 | 15 天後 |
|---|---|---|---|
| 30 字（3 關） | 60–75 題 | 30–40 分 | 約 450 字 |
| 45 字（5 關） | 90–110 題 | 45–55 分 | 約 675 字 |
| 67 字（7 關） | 130–150 題 | 60–75 分 | 1002 字＝一整級 |
| 400 字 | 800–1000 題 | 3.5–5 小時 | 全書 6012 字（不現實） |

## 每日簽到（7 天一輪的獎勵軌道）

當天第一次通關自動簽到。同一輪裡**一天比一天多**，第 3、5 天附道具，**第 7 天直接給金寶箱**。
連續不中斷 → 進入下一輪，整輪獎勵再 ×1.15（最多 ×2）。
里程碑：連續 **14／30／60／100 天** 另外給大量金幣、道具與外觀解鎖。
首頁把這一輪 7 天全部畫出來，看得到後面有什麼在等。

## 任務看板（每日／每週／每月）

| 分頁 | 內容 |
|---|---|
| 每日 | 4 個固定任務 ＋ 每天各抽一個「連擊／題型／探索」挑戰 ＋ **今日主打關**（抽一個字母關，通關給大獎） |
| 每週 | 從 11 個週任務抽 4 個（學會 50／100 字、通關 10 關、天天學習、正確率 80%、累積 90 分鐘…） |
| 每月 | 從 7 個月任務抽 3 個（學會 200 字、通關 40 關、學習 20 天、累積 10 小時…） |

- 每個任務都有**進度條**（目前／目標），不只是「完成／未完成」。
- **達成過就永久釘住**：之後正確率掉了、又有新字到期，都不會把已完成的任務退回未完成；達成時間會記進紀錄。
- 獎勵在關卡結算時自動入帳，不用另外領。

## 成就（🏅 30 個，分五級）

首頁 →「🏅 成就」。分**普通／稀有／史詩／傳說／究極**五級，未達成的都畫進度條（差多少一目了然）。

| 等級 | 例子 |
|---|---|
| 普通 | 啟程、三日不斷、百字斬、十連擊、無傷通關、開箱人 |
| 稀有 | 七日不斷、千字斬、廿五連擊、造句手、文法第一階、礦工（100 顆寶石）、踏遍五十關 |
| 史詩 | 一月不輟、兩千字斬、五十連擊、長期記憶千字、Lv.20、星塵滿載、百句作家、地獄常客（地獄難度通關 10 次） |
| 傳說 | 四千字斬、**百日不輟**、**文法全通**（32 點全精熟）、**走完全圖**（每個字母關都過）、**全三星** |
| 究極 | **🏆 全書背完**（6012 字全部學會）、**🏆 全書精熟**（每個字都推進 box 5 以上的長期記憶） |

究極成就少一個字都不算。以每天 60 字估算，「全書背完」大約 100 天；「全書精熟」還要再加上完整的複習週期。

## 升等獎勵

每滿 400 XP 升一級，升等就給獎勵：金幣（隨等級遞增）、偶數等給一個消耗品，
**Lv.5 解鎖森林主題、Lv.8 苦讀生稱號、Lv.12 夕陽主題、Lv.16 獵字人稱號**。同一等只發一次。

## 寶箱（🎁 全螢幕開箱）

通關才有寶箱，而且**大寶箱不是隨便給的**：

| 寶箱 | 條件 | 抽獎次數 | 金幣／XP |
|---|---|---|---|
| 📦 木 | 通關 | 1 | 8–18 / 20–45 |
| 🎁 銀 | 全對（小關）／二星沒重來／本關連擊 ≥12 | 2 | 22–40 / 55–100 |
| 💎 金 | **10 題以上全對且沒重來** | 3 | 50–85 / 120–200 |
| 🌈 彩虹 | **20 題以上全對、連擊 ≥20、挑戰難度以上、沒重來** | 4 | 130–240 / 320–520 |

- 小關卡（5 題）全對只給銀 —— 不能靠刷短關拿金寶箱。
- 一般升級（獨角獸夥伴）最多升到金；**只有加碼題能把金推上彩虹**。
- **加碼題題數跟著關卡規模**：一關的 ⅓（3～8 題），所以 10 題的關卡是 3 題、24 題的關卡是 8 題。
  不扣血、答錯不倒扣：全對升 **2 級**（＋60 XP）、答對六成以上升 1 級（＋25 XP）、不到就維持原箱。
- **加碼題一定是不同的單字**：只出「這一關範圍內（同級同字母）、剛剛沒考過的字」，
  沒學過的排前面。同一個字最多一題。
  這個字母的字如果全部考完了，就**不給加碼題**（寧可不給，也不重複考一樣的字）。
- 開箱是**全螢幕畫面**：三個箱子排開讓你自己挑，選完箱子放大、獎品一項一項亮出來。
- **不想現在開就先收起來**：**所有來源的寶箱**（通關、加碼題升級、寶箱鑰匙、每日簽到第 7 天、
  連續天數里程碑）都會先進背包，不會過期。之後在背包按「🎉 一次全開」（顯示總計與逐箱明細）。
- 背包裡只要有沒開的寶箱，**頂端會顯示 🎁 數量、首頁也會有一張提醒卡**，可以直接一次全開。

**開箱內容是加權抽獎**，稀有獎品在木寶箱幾乎抽不到，金／彩虹才有像樣的機率：

| 類型 | 內容 |
|---|---|
| 一般 | 藍／綠／紅寶石、星塵、古卷軸、刪去法、護心符、沙漏 |
| 稀有 | 💎 金鑽石、雙倍／大護心符、大沙漏、連勝護盾 |
| 驚喜（機率很低） | 🔑 寶箱鑰匙、復活石、三倍 XP 卡、🪙 金幣大獎（150–400）、✨ XP 大獎（200–500） |
| 究極驚喜 | 🎀 **神秘禮物** —— 隨機送一件你還沒有的史詩／傳說／究極商品（護符、夥伴、主題）；全都有了就換成 500+ 金幣 |

開出稀有獎品時會有彩虹底色與升級音效，全部明細都寫進寶箱紀錄。

## 背包與素材（🎒）

通關會掉**素材**，素材只能靠實際闖關拿到，**商店買不到**：

| 素材 | 哪裡來 |
|---|---|
| 🔹 藍寶石 / 💚 綠寶石 / ❤️ 紅寶石 | 通關掉落，級別越高掉越好（1–2 級藍、3–4 級綠、5–6 級紅） |
| 💎 金鑽石 | 三星通關才有機會掉 |
| ✨ 星塵 | 本關連擊 ≥8 才掉，連擊越高掉越多 |
| 📜 古卷軸 | 通關隨機掉 |
| 🔑 寶箱鑰匙 | 三星通關少量掉落，或用金鑽石＋古卷軸合成；在背包裡直接開一個銀寶箱 |

背包裡有**合成台**：素材（＋少量金幣）換道具 —— 刪去法、護心符、沙漏、雙倍／三倍 XP 卡、復活石、連勝護盾、鑰匙。
背包同時是道具存量與收藏（主題／稱號／夥伴）的裝備處，並列出今天收到的素材與來源。

每日任務裡也有「收集 6 顆寶石」「合成 1 個道具」，每週任務有「收集 30 顆寶石」。

## 金幣與商店

金幣來自通關（星數越高越多）、寶箱、每日任務、簽到、升等。認真學一天大約 300–600 金幣，
而**價格是北歐物價**：護符要存好幾天、夥伴與究極外觀要存好幾週。東西貴，拿到才有感覺。

**🔥 今日特價**：每天用日期抽兩件貴的商品打 **75 折**（重整頁面不會換，隔天才換），買的時候扣的就是特價。
**已經擁有的單品（主題／稱號／夥伴／護符）不會再上特價**；這類只能有一個的東西在畫面上也只顯示「已擁有」，不顯示數量。

| 類型 | 商品（稀有度：普通／稀有／史詩／傳說／究極） | 價格帶 |

## 間隔複習與錯題加強

答對的字會照 **1 → 3 → 7 → 14 → 30 → 60 天** 往後排；答錯直接掉回第一格（當天重練、隔天必考）。
首頁會顯示今天有幾個字到期，一鍵開始複習。

> 實測：掃過全部 444 個關卡（6 級 × 每個字母 × 3 次、共 4275 道單字題），
> **不同級或不同字母的字：0 題**。
> 但代價要說清楚：例句目前只有 L3（90 字）與 L4（60 字），所以**只有第 3、4 級的關卡出得出句子題**
> （444 關共 194 題，全部落在 3、4 級）。第 1、2、5、6 級目前完全沒有句子題 —— 要靠擴充例句庫解決。

**錯題會被加強出題**，三層機制同時作用：

1. **抽題權重**：每個字都有出題權重 = 1 ＋ 錯的次數 ×0.8（上限 4）＋ 上次答錯 ×2 ＋ 三天內錯過 +1，
   連續答對每次 −0.4。權重用加權隨機抽樣（不是硬排序），所以錯題明顯更常出現，但沒錯過的字仍然抽得到。
   闖關、複習、自訂練習、訂正關全部吃這個權重。
2. **同一關內當場補考**：答錯之後，這一關後面會自動插入一題**同一個字、換一種題型**的補考（隔 3 題以上，每字最多 2 次）。
   補考題面上會標「🔁 剛才錯過的字，再練一次」，並且**記成第 2 次作答** —— 不會洗掉「首次正確率」。
3. **錯題關 / 難字特訓**：首頁的「🔁 錯題加強」卡直接開專門的關卡（不扣血）。
   錯 3 次以上還沒練起來的字會被標成**難字**，可以只練難字，家長回報也會單獨列出來。

錯題本收「錯過而且 box < 4」的字；練到 box 4 以上就會自動從錯題本移除。

## 家長回報

```
【英文學習回報】2026/07/25（五）

■ 今天複習的單字：共 28 題 → 對 24 個、錯 4 個（正確率 86%）
■ 造句運用：4 題 → 對 3 個
■ 文法練習：3 題 → 對 2 個（現在完成式 vs 過去簡單式）
■ 今天實際練習時間：24 分 10 秒（共闖 4 關，通關 3 關）
■ 今天完成的任務：5 項

累積已學會 312 字 ／ 全書 6012 字（5.2%）
連續學習 12 天 ・ 今日獲得 320 XP ・ 等級 Lv.8

今天答錯、需要加強的字（4）：abandon、adequate、…
```

正確率**一律只採計當日第 1 次作答**，重來的第二次不列入，數字不會虛胖。

## 迷因台詞（讀累了看一句廢話）

讀 60 分鐘單字很枯，所以在「抬頭喘口氣」的位置各放一句吐槽：答對／答錯的回饋、連擊里程碑、
通關與 GAME OVER、開寶箱（四種箱子各有自己的台詞）、升等、每日簽到、學習卡、到期複習、
錯題關、快速篩選、加碼題，以及首頁的「**今日廢話**」（用日期抽，一天固定一句）。

還有 **⏸ 暫停 → 「ZA WARUDO！時よ止まれ」**、**▶ 繼續 → 「そして時は動き出す」**、
通關 → 「最高に『ハイ！』ってヤツだアアア」這類動漫／遊戲梗（都附中文，看不懂原文也知道在幹嘛）。

**同一個情境的台詞用「洗牌袋」抽**：全部輪過一遍才可能重複，換袋子時也會避開上一句 ——
所以不會連續看到同一句廢話。

內容放在 `data/memes.js`（217 句），改的時候有三條規矩，`node src/validate.js` 會檢查：

1. **只吐槽單字、系統、我自己，不吐槽學生** —— 答錯的時候要好笑，不能難受
   （驗證會擋掉「笨／蠢／廢物／沒救」這類字眼）
2. 一句 32 字以內、純文字（不放圖，離線也能跑）
3. 不影響判分與紀錄，設定頁可以一鍵關掉

## ⌨ 鍵盤快速鍵（整條動線不用滑鼠）

| 動作 | 預設鍵 |
|---|---|
| 下一題 / 繼續 | **空白鍵** |
| 送出答案 | **Enter**（多行的自由造句用 **Ctrl+Enter**，Enter 是換行） |
| 學習卡：記住了，下一個 / 開始闖關 | **空白鍵** |
| 學習卡：上一個 | **⌫ Backspace** |
| 學習卡：這個我早就會了 | **Delete** |
| 重播發音 | **Shift** |
| 使用刪去法 | **F** |
| 暫停 / 關閉視窗 | **Esc** |
| 結算畫面的主要按鈕（開寶箱／下一關／繼續練習…） | **Enter** |
| 選擇題選項 | **1 / 2 / 3 / 4** |

**「前進」那一族的鍵互通**：空白鍵、Enter 在「下一題／學習卡下一個／結算主按鈕」都能用，
不會出現「按 Enter 沒反應」。作答與學習卡畫面底部還有一條**快速鍵提示條**（設定可關）。

- 每個動作都能在**設定頁改鍵**：點「改鍵」後直接按你要的鍵（Shift、Delete、空白鍵都可以），
  按錯了有「還原成預設鍵」。
- 同一個鍵可以綁在不同動作上（例如空白鍵同時是「下一題」與「學習卡下一個」），
  系統依當下畫面決定要做什麼。
- **在輸入框打字時，可打字的鍵不會觸發快速鍵**（空白鍵就是空白鍵）；答完題目輸入框會自動失焦，
  所以馬上按空白鍵就能到下一題。
- 按鈕上直接印著對應的鍵（例如「下一題 `Space`」），不用背。

## 設定

- **每關題數**：預設值，實際開關卡時還可以再選。
- **關卡難度**：輕鬆／標準／挑戰／地獄。
- **每關題數與題型組成**：一關幾題、其中幾題句子運用、幾題文法、有例句的字考句子的比重（0–100）。
  設定頁會直接算給你看「這一關會長成什麼樣」，並顯示目前有例句的字有幾個。
- **要練哪些題型**：12 種題型可以逐一開關，關掉的就不會再出現（至少要留一種）。
  例如不想練聽力就把「聽發音」關掉，不想手寫就關掉「拼字」與「找錯改錯」。
- **顯示迷因台詞**：預設開，關掉之後所有吐槽與「今日廢話」都不出現。
- **聽力題的發音**：自動唸**兩次**、有「🐢 慢速播放」（0.45 倍速再唸兩次），真的聽不出來還可以按「看音標」。
  聽音辨字的選項會用**音標距離**過濾掉「聽起來幾乎一樣」的字（rice /raɪs/ 與 raise /reɪz/ 不會同時出現）。
  語音會優先挑 Windows 的 Natural／Neural 語音。
- **發音速度**：預設 **75%**（比母語者慢，聽得清楚每個音節），可在 50–110% 之間調，旁邊有試聽鈕。
- 每題倒數計時、每題答完立刻對答案、音效、單字發音。
